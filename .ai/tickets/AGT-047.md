# AGT-047 — Inline Role Description for Each Agent in the Trace

Status: Backlog
Depends On: None
Category: Improvement

## Description

Found 2026-10-05: the project owner could tell what Gatekeeper and Research do from the trace
alone, but asked directly "what is the role of the Writer?" -- the trace shows a node labeled
"Writer" with a one-line summary of *its output*, never *what it does*. The `/about` page already
explains all four roles in prose, but that's a separate page, not inline where you're actually
looking at a trace.

## Acceptance Criteria

- [ ] Each agent node in `TraceStepper` (`AGT-039`) shows a short, fixed role description next to
      (or just under) its name -- e.g. "Writer -- drafts a cited answer from the evidence" --
      reusing the same four descriptions already written for `/about`, not new copy
- [ ] Descriptions are static per agent type, not per-query -- this is "what this agent generally
      does", not a summary of what it did this time (that's the existing one-line summary,
      unchanged)
- [ ] Deployed and visually confirmed

## Notes

Small, self-contained -- a constant lookup table in `TraceStepper.tsx`, no backend change. Pairs
naturally with `AGT-046` (once citations are visible, "grounded" is self-evident; once roles are
labeled, "what does the Writer do" is self-evident) but neither blocks the other.
