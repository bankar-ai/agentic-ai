# AGT-037 — Query Page: Proper App Header + Tabs (Tailwind)

Status: Backlog
Depends On: None
Category: Improvement

## Description

Live screenshot review (2026-10-04) found the deployed query page reads as unstyled: a flat gray
page, floating pill buttons for mode selection sitting under a paragraph of body text, no visual
hierarchy. `enterprise-rag-platform`'s frontend (`frontend/src/components/AppShell.tsx`) already
solves this with Tailwind — a white header bar, app name left, nav/tabs center-right, user info
and logout right. Bring that same structure (and Tailwind itself) into `agentic-ai`'s frontend.

This is the foundation ticket: adds the Tailwind dependency and the header shell that `AGT-038`
and `AGT-039` build inside.

## Acceptance Criteria

- [ ] Tailwind CSS added to `frontend/` (matching `enterprise-rag-platform`'s setup: `@tailwindcss/vite`,
      slate palette), existing plain CSS in `index.css` migrated or removed as each component
      converts
- [ ] `QueryPage.tsx` gets a proper header: app name/logo left, Agentic/Direct mode toggle
      rendered as real tabs (underline-style) rather than floating pill buttons, user email +
      logout right — styled per `enterprise-rag-platform`'s `AppShell.tsx` conventions
- [ ] The explanatory "Compare a single raw retrieval pass against..." sentence becomes a small
      `?`/info affordance next to the tabs instead of a full paragraph competing with the header
- [ ] Desktop/laptop viewport only (no mobile-specific layout work) — see `AGT-042`
- [ ] No flicker on mode-tab switch: switching tabs never clears or blanks content that doesn't
      need to change
- [ ] Deployed and visually confirmed against the live Vercel URL

## Notes

Mode switch itself currently triggers no fetch (toggling is instant, client-only state) — confirm
this stays true after the redesign so there's nothing to flicker on tab switch specifically.
