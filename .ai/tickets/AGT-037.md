# AGT-037 — Query Page: Proper App Header + Tabs (Tailwind)

Status: Done
Depends On: None
Category: Improvement

## Description

Live screenshot review (2026-10-04) found the deployed query page reads as unstyled: a flat gray
page, floating pill buttons for mode selection sitting under a paragraph of body text, no visual
hierarchy. `enterprise-rag-platform`'s frontend (`frontend/src/components/AppShell.tsx`) already
solves this with Tailwind — a white header bar, app name left, nav/tabs center-right, user info
and logout right. Bring that same structure (and Tailwind itself) into `agentic-ai`'s frontend.

This is the foundation ticket: adds the Tailwind dependency and the header shell that `AGT-038`
and `AGT-039` build inside.

## Acceptance Criteria

- [x] Tailwind CSS added to `frontend/` (matching `enterprise-rag-platform`'s setup: `@tailwindcss/vite`,
      slate palette), existing plain CSS in `index.css` migrated or removed as each component
      converts
- [x] `QueryPage.tsx` gets a proper header: app name/logo left, Agentic/Direct mode toggle
      rendered as real tabs (underline-style) rather than floating pill buttons, user email +
      logout right — styled per `enterprise-rag-platform`'s `AppShell.tsx` conventions
- [x] The explanatory "Compare a single raw retrieval pass against..." sentence becomes a small
      `?`/info affordance next to the tabs instead of a full paragraph competing with the header
- [x] Desktop/laptop viewport only (no mobile-specific layout work) — see `AGT-042`
- [x] No flicker on mode-tab switch: switching tabs never clears or blanks content that doesn't
      need to change
- [x] Deployed and visually confirmed against the live Vercel URL

## Notes

Mode switch itself currently triggers no fetch (toggling is instant, client-only state) — confirm
this stays true after the redesign so there's nothing to flicker on tab switch specifically.

## Resolution (2026-10-04)

Added Tailwind CSS v4 (`@tailwindcss/vite`) to `frontend/`; `index.css` reduced to just the
Tailwind import and a couple of global resets, every component now styled with Tailwind utility
classes matching `enterprise-rag-platform`'s slate palette and spacing conventions.
`QueryPage.tsx` header rebuilt: app name left, Agentic/Direct as real underline tabs, `?` link +
email + logout right. Mode switch remains pure client-side state (no fetch), confirmed no
flicker. Deployed as commit `365d7f1` on `main`; live-verified the production bundle
(`index-CLNigrr8.js`, later `index-DO0HkaMS.js` after `AGT-042`) contains the new header strings
and the generated Tailwind CSS (17KB+) matches the local build byte-for-byte.
