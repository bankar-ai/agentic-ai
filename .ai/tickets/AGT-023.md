# AGT-023 — Rename Vercel Project to Match `enterprise-rag-platform`'s Convention

Status: In Progress
Depends On: None
Category: Improvement

## Description

`agentic-ai`'s Vercel project still has its auto-generated subdomain
(`agentic-ai-psi-mauve.vercel.app`). `enterprise-rag-platform` hit the exact same cosmetic issue
and fixed it the same way (`ERP-057`): renamed the Vercel project to a readable, org-prefixed
name (`bankar-ai-self-hosted-rag-platform.vercel.app`). Do the same here for consistency across
the portfolio.

**Known gotcha from ERP-057, applies identically here:** the backend's CORS allowlist is an exact
string match on Origin — renaming the Vercel project without updating `CORS_ALLOWED_ORIGINS` on
Cloud Run breaks login silently (browser blocks every cross-origin request, no server-side error
to find). Both must change together.

## Acceptance Criteria

- [ ] Vercel project renamed to `bankar-ai-agentic-ai` (new URL:
      `https://bankar-ai-agentic-ai.vercel.app`)
- [ ] `CORS_ALLOWED_ORIGINS` on the `agentic-ai` Cloud Run service updated to the new origin
- [ ] Live-verified: a real login + query against the new URL succeeds (or fails for an unrelated
      reason, not a CORS block)
- [ ] `gcp-deployment-tracker.md` updated with the new URL
