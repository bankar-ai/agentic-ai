# AGT-049 — Query Page Layout: Sidebar + Bottom-Anchored Input, Chat-Style

Status: Done
Depends On: AGT-037
Category: Improvement

## Description

Found 2026-10-05, project owner's own words: "docs should be on the left panel or sidebar... why
the content is in the middle only... ask should come at the bottom -- like it is in the chatbot
(rag platform)... history should be above the ask bar." The current layout (`AGT-037`'s redesign)
is a single centered column (`max-w-3xl mx-auto`) with documents/history as collapsed `<details>`
sections stacked above a mid-page input -- functional, but doesn't use the available width on a
laptop/desktop screen and doesn't match the chat-style interaction pattern
`enterprise-rag-platform`'s own `ChatPage.tsx` already established in this portfolio (a real left
`Sidebar` component + `<main className="flex min-w-0 flex-1 flex-col">`, input anchored at the
bottom of the main pane).

This is a real layout restructuring, not a small tweak -- worth its own short design pass before
implementation (which components move where, what persists vs. collapses, whether this becomes a
genuine two-pane `flex` layout like `ChatPage.tsx` or something lighter), not just logged and
implemented blind.

## Acceptance Criteria

- [x] Documents panel becomes a persistent left sidebar (not a collapsed `<details>` in the main
      column), styled per `enterprise-rag-platform`'s `Sidebar.tsx` conventions
- [x] Main content area uses the full remaining width, not a centered `max-w-3xl` column
- [x] The question input is anchored at the bottom of the page/pane (chat-style), not mid-page
      above an empty space
- [x] History sits above the input (last thing in the scrollable content, directly above the
      fixed input bar), not below the result panel as it was before
- [x] Result panel (verdict/answer/trace, `AGT-039`) remains the main focus of the content area
- [x] Desktop/laptop is the real target; mobile stacks (sidebar above the rest) rather than
      breaking, though full polish stays `AGT-042`'s follow-up
- [x] Deployed; visually confirmed via code review + a local preview server render check (no
      browser tool to physically view it, see Resolution)

## Notes

Needs a short bounded-path design pass (`superpowers:brainstorming`) before implementation --
this is a real restructuring of `QueryPage.tsx`'s component tree, not a CSS-only change, and
touches every other recent ticket's components (`AGT-038`'s documents panel, `AGT-039`'s result
panel, `AGT-040`'s history panel). Reference: `enterprise-rag-platform/frontend/src/pages/
ChatPage.tsx` + `components/Sidebar.tsx`.

## Resolution (2026-10-05)

Restructured `QueryPage.tsx`: outer `flex h-screen flex-col md:flex-row` -- a persistent `<aside>`
(documents, `md:w-72 md:border-r`) and a right column (`header` with mode tabs/user controls,
`main` scrollable with result + history, `footer` with the question form anchored at the bottom).
Stacks vertically below `md` (sidebar above the rest) rather than hiding anything, so mobile keeps
working even without dedicated polish. Deployed as part of commit `1a5631c` on `main`; build/
typecheck clean, and a local `vite preview` render confirmed the new bundle serves correctly. Not
physically viewed in a browser by a human this session.
