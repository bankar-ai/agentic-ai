# AGT-024 — "About This App" Page

Status: In Progress
Depends On: None
Category: Feature

## Description

A first-time visitor lands straight on a login form with no context: what this app does, what it
expects (a real `enterprise-rag-platform` account with content already ingested — there is no
shared demo account, `AGT-006`), and what it doesn't do. Add a short info page so expectations are
set before login, not discovered via an error message.

## Acceptance Criteria

- [ ] New `/about` route (React Router) with: what the app is (agentic RAG orchestration demo —
      Gatekeeper → Research → Writer → Verifier), what it needs (a real `enterprise-rag-platform`
      account with ingested content — no demo account), and what it doesn't do (no file upload
      here — ingest documents on `enterprise-rag-platform` directly)
- [ ] Linked from the login page
- [ ] Deployed to Vercel, live-verified
