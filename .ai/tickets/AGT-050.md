## Description

Found 2026-10-05: the history panel still reads "Past questions, this browser only" -- true when
that copy was written (`AGT-027`, client-side-only `localStorage`), no longer true since `AGT-041`
(server-side `query_history` table) and `AGT-044` part 2 (`GET /history`, cross-device
reconciliation) shipped. The project owner's own reaction: "why is it saying this browser only --
we have a dedicated DB for it also we are caching -- so this shouldn't make any sense." They're
right; this is leftover copy from before the architecture changed underneath it, not a design
decision anyone re-confirmed.
