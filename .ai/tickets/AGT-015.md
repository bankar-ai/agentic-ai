# AGT-015 — Architecture Diagram

Status: Done
Depends On: None
Category: Improvement

## Description

`enterprise-rag-platform` has `docs/diagrams/architecture.drawio` (editable in draw.io) + an
exported PNG, plus a separate `system-flow.svg`. This project had no diagram at all.

## Acceptance Criteria

- [x] A diagram added to `docs/architecture.md` showing the real component flow: entry points
      (API/UI) → LangGraph (4 agents) → MCP tool server/subprocess → `enterprise-rag-platform`,
      plus the LLM provider and Langfuse tracing as side dependencies

## Notes

**Format differs from the sibling repo deliberately, not by oversight**: `enterprise-rag-platform`'s
diagram is draw.io XML + an exported PNG, produced with a GUI drawing tool. No such tool is
available in this environment, and a hand-written `.drawio` XML file can't be visually verified
before committing it — a real risk of shipping something subtly broken that nobody actually
checked. Used a **Mermaid diagram** instead, embedded directly in `docs/architecture.md`: renders
natively on GitHub (no separate PNG export needed, never goes stale relative to the file that
describes it), and it's plain text, so it can be read and reasoned about like any other code
rather than trusted blind. If draw.io parity is wanted later, this is a quick manual follow-up
once there's access to an actual drawing tool.
